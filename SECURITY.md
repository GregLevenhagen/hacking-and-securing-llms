# Security Policy

If you discover a security issue in this repository, do not open a public issue with exploit details.

Please report it privately to the maintainer through GitHub security advisories or a direct maintainer contact channel if one is available.

When reporting an issue, include:

- affected file or demo
- reproduction steps
- impact
- whether the issue affects sample code only or the shared framework

This repository contains intentionally vulnerable demos for educational purposes. Reports should distinguish between:

- expected insecure behavior demonstrated on purpose
- accidental vulnerabilities in shared tooling, setup scripts, or unintended exposures
