# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our Standards

Examples of behavior that contributes to a positive environment:

- being respectful and constructive
- accepting feedback in good faith
- focusing on technical substance rather than personal attacks
- helping keep security discussions responsible and clear

Examples of unacceptable behavior:

- harassment or abusive language
- publishing private information without permission
- disruptive, bad-faith, or intentionally hostile conduct

## Enforcement

Project maintainers may remove, edit, or reject contributions and participation that violate this code of conduct.

## Scope

This applies within project spaces and in public interactions representing the project.
